## 1. 현대모비스 (012330 · 코스피) — 회사분할(물적) + 램프사업 매각 ●

>> 팩트: 현대모비스 → 램프사업부 **물적분할**(분할기일 **2027-04-01**) → 신설 현대모비스 램프(비상장) → **OP모빌리티 SE** SPA → 약 **6,000억**(국내외 램프사업 일괄, 보도 기준)

- **배경**: 2025-12-26 거래소 조회공시 이후 9개월 만에 확정됨. 30일 임시이사회에서 분할·SPA 동시 승인됨 ([한국경제](https://www.hankyung.com/article/2026093055731), [뉴데일리](https://biz.newdaily.co.kr/site/data/html/2026/09/30/2026093000364.html))

- **구조**: 국내 램프 자회사 지분은 신설법인에 들어가고, 해외 램프법인은 존속법인이 보유하다가 별도로 매수인 측에 매각함(원문 확인)
- **밸류 감**: 국내 매출만으로 단순 계산하면 **0.6x 매출** 수준임. 보도대로 해외 법인까지 포함된 가격이라면 실제 배수는 이보다 낮음 — 저마진 램프 사업에 대한 할인 매각으로 해석됨
- **주총**: 11/24 임시주총 특별결의. 반대주주 주식매수청구권 행사기간은 11/24~12/14이고(자본시장법 165조의5), 최대주주 지분 변동은 없음
- **PE 시사점 ⓐ**: SI가 인수한 딜이라 직접 참여 여지는 없음. 대신 현대차그룹이 **저마진·비핵심 부품 라인 정리**를 확인시켜 준 선례임
- **PE 시사점 ⓑ**: 후속 carve-out 후보(현대모비스 비주력 모듈, 계열 부품사 비핵심 라인)가 PE용 매물로 나올 가능성이 있어 워치할 필요가 있음
- **PE 시사점 ⓒ**: OP모빌리티가 국내 생산기지를 재편하면 협력 램프 부품 벤더(Tier2)의 매각 수요가 생길 수 있음

## 2. 한화투자증권 (003530 · 코스피) — 제3자배정 유상증자 5,000억 ◐
- **공시**: 주요사항보고서(유상증자결정) (09/30) — [DART 원문](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260930000770)
>> 팩트: 한화자산운용(최대주주) 보통주 **5,000만주** + 한화생명 CPS **5,000만주** → 주당 **5,000원**(기준주가 4,527원 대비 **+10.4% 할증**) → 총 **5,000억** 운영자금
>> 앵글: 그룹 내부 자본확충 → 종투사(자기자본 3조) 진입 → 증권사 IB·PI 확대 → 인수금융·메자닌 공동투자 상대방 증가
- **배경**: 신종자본증권 최대 4,000억까지 합쳐 최대 **9,000억** 자본확충이고, 목적은 종투사 진입임 ([딜사이트](https://dealsite.co.kr/articles/169930), [뉴스웨이](https://www.newsway.co.kr/news/view?ud=2026093018012996367))
- **CPS 조건**: 의결권 없음, 액면 기준 **연 6% 누적적·비참가적** 우선배당, 존속기간 2056-10-09(원문 확인). 1년 보호예수
- **희석**: 신주 1억주로 기존 발행주식(보통 2.15억+기타 0.05억) 대비 **약 45%** 증가함. 할증 발행이라 소액주주 희석 부담은 줄어듦
- **PE 시사점 ⓐ**: 외부 FI 몫은 없어 투자 앵글은 없음
- **PE 시사점 ⓑ**: 종투사 지정 이후 기업신용공여 한도가 커지므로 **인수금융·브릿지 공급처가 하나 늘어나는** 효과가 있음 — 딜 파이낸싱 소싱처로 관리할 만함
- **긴급도**: 중기 · **반증**: 종투사 지정이 지연되거나 증자분이 IB 확대 대신 부동산PF 충당에 쓰이면 파이낸싱 상대방으로서의 앵글은 약해짐

## 3. 우진아이엔에스 (010400 · 코스피) — 2세 승계 + 주주제안 임시주총 ◐
- **공시**: 주식등의대량보유상황보고서(신규, 대표보고자 변경) (09/30) — [DART 원문](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260930000665) · 의결권대리행사권유 — [DART 원문](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260930000555)
>> 팩트: 홍평우 → 홍경모 **3,797,730주 증여** → 홍경모 측 **52.23%**(398만주/762만주) → 10/8 임시주총 **주주제안 5건** → 회사가 "경영권 안정" 명목으로 위임장 권유
>> 앵글: 승계 완료 → 증여세 재원 수요 → 주주제안 표대결(감사 선임 3%룰) → 밸류업 압박·오너 유동성 추적
- **주주제안 안건**: 집중투표 관련 정관 변경, 자기주식 취득(약 75억), 자사주 **517,530주** 전량 소각, 자본준비금 감액(100억), 비상근 감사 1인 추가 선임

- **승계 부담**: 49.8% 증여라 증여세 규모가 클 것으로 보임(금액 미확인). 연부연납·주식담보·배당 확대 중 어떤 경로로 재원을 마련하는지가 관전점임
- **PE 시사점 ⓐ**: 증여세 재원 마련 과정에서 오너 지분 일부 블록딜이나 EB 발행 가능성이 있음 — 소수지분 투자 기회로 연결될 수 있음
- **PE 시사점 ⓑ**: 주주제안 측 정체(행동주의 펀드 여부)는 미확인이라 주총 결과 공시로 확인이 필요함
- **긴급도**: 즉시(10/8 주총) · **반증**: 감사 안건까지 부결되고 오너가 연부연납만으로 증여세를 처리하면 지분 유동화 앵글은 없음

## 4. 아이씨티케이 (456010 · 코스닥) — 타법인주식 양수(위드네트웍스) ◐

- **PE 시사점 ⓑ**: 아이씨티케이가 추가 M&A를 하려면 자금이 필요해질 수 있음. 향후 CB·3자배정이 나오면 참여를 검토할 만함
